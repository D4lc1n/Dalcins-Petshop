1. Objetivo e Metas

Objetivo Geral

Desenvolver um sistema web de front-end para o Dalcin's Petshop, permitindo que clientes visualizem os produtos e servicos do estabelecimento de forma clara e organizada pela internet.

Objetivos Especificos / Metas

  • Criar paginas HTML validas e bem estruturadas para apresentacao do petshop.
  • Exibir ao menos 3 categorias de produtos com 2 produtos cada (foto, descricao e valor).
  • Listar os servicos oferecidos com descricao, valor e indicacao de tele-busca.
  • Incluir cabecalho (header) com nome do petshop e menu de navegacao em todas as paginas.
  • Incluir rodape (footer) com informacoes legais, contato e links de navegacao.
  • Disponibilizar pagina de ajuda descrevendo as funcionalidades do sistema.
  • Publicar o sistema no GitHub Pages para acesso publico via internet.

3. Arquitetura Web Utilizada

Tipo de Aplicacao Web

O sistema e uma aplicacao web estatica, ou seja, os arquivos HTML sao entregues diretamente ao navegador do usuario sem processamento no servidor. Nao ha banco de dados nem linguagem de programacao no servidor nesta fase. Trata-se de um site institucional com multiplas paginas interligadas por hiperlinks.

Arquitetura Baseada em Servicos ou Microservicos?

Nao. Por se tratar de um site estatico na Fase 1, nao ha arquitetura de servicos ou microservicos. Toda a logica esta contida nas proprias paginas HTML. Em fases futuras, podera ser adotada uma arquitetura cliente-servidor com back-end para gerenciar pedidos, cadastros e autenticacao de usuarios.

Dimensoes da Aplicacao Web

  • Apresentacao (Front-end): Paginas HTML estruturadas com tags semanticas.
  • Dados: Nesta fase, os dados (produtos e servicos) estao incorporados diretamente no HTML (dados estaticos).
  • Back-end: Nao implementado na Fase 1. Previsto para fases futuras.

4. Protocolos Utilizados

Protocolos de Rede

Protocolo Camada Funcao no Projeto
TCP/IP Transporte / Internet Responsavel pela transmissao confiavel dos dados entre cliente e servidor
DNS Aplicacao Traducao do nome de dominio (URL) para o endereco IP do servidor

Protocolos de Aplicacao

Protocolo Funcao no Projeto
HTTP / HTTPS Protocolo de transferencia de hipertexto. O navegador faz requisicoes HTTP GET para o servidor (GitHub Pages), que responde com os arquivos HTML, imagens, etc. O GitHub Pages utiliza HTTPS por padrao, garantindo criptografia na comunicacao.
HTML (HyperText Markup Language) Linguagem de marcacao utilizada para estruturar todo o conteudo das paginas do site. Versao utilizada: HTML5.

5. Front-end e Back-end

Front-end

O front-end e toda a parte visivel ao usuario no navegador. Nesta fase, e composto exclusivamente por HTML5. Nao foram utilizados CSS (folhas de estilo) nem JavaScript nesta etapa, conforme requisito da Fase 1.

Tecnologias de front-end utilizadas na Fase 1:

  • HTML5 - estrutura e conteudo das paginas
  • Tags semanticas: <header>, <nav>, <main>, <footer>, <table>, <form>
  • Hiperlinks para navegacao entre paginas
  • Imagens via tag <img> com atributos alt para acessibilidade

Back-end

Nao ha back-end implementado na Fase 1. O servidor utilizado e o GitHub Pages, que e um servidor de hospedagem de arquivos estaticos. Ele entrega os arquivos HTML ao navegador sem nenhum processamento dinamico. O formulario de contato existe na pagina, mas ainda nao possui acao real de envio (sera implementado em fases futuras).

6. Padroes e Frameworks

Padroes Utilizados

  • HTML5 (W3C): As paginas seguem o padrao HTML5 definido pelo World Wide Web Consortium (W3C), utilizando DOCTYPE, charset UTF-8, meta viewport e tags semanticas.
  • UTF-8: Codificacao de caracteres utilizada em todas as paginas, garantindo suporte correto a caracteres especiais do portugues.
  • Acessibilidade basica: Uso do atributo alt nas imagens e atributos for/id nos formularios.

Frameworks

Nenhum framework foi utilizado na Fase 1. O requisito da disciplina determina que nesta etapa nao devem ser usados CSS nem Bootstrap. O desenvolvimento e feito apenas com HTML puro. O uso de Bootstrap (framework CSS) esta previsto para fases futuras.
