# Dalcin's Petshop 🐾

Projeto desenvolvido para a disciplina **Fundamentos e Sistemas Web**  
Curso: Análise e Desenvolvimento de Sistemas

---

## Sobre o Projeto

Site institucional do Dalcin's Petshop, desenvolvido em HTML5 puro (sem CSS e sem JavaScript) na Fase 1.

## Páginas

| Arquivo | Descrição |
|---|---|
| index.html | Página inicial |
| produtos.html | Catálogo de produtos (3 categorias, 2 produtos cada) |
| servicos.html | Serviços com valores e tele-busca |
| contato.html | Formulário e informações de contato |
| ajuda.html | Guia de funcionalidades do site |
| documento.html | Documento técnico do projeto (objetivos, arquitetura, protocolos) |
